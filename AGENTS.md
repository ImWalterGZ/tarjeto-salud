# Tarjeto Salud — contexto del proyecto

Proyecto escolar independiente para demostrar una app de salud. No pertenece al Tarjeto oficial ni comparte sus servicios o despliegues. Este contexto específico prevalece sobre las descripciones generales de Tarjeto en directorios superiores.

Base copiada de `tarjeto/tarjeto-landings`, rama `feat/tarjeto-salud-privacidad`, commit `7cac474a63493a26bfd941007fd72680171e5fff`, con historial Git nuevo.

La copia conserva contenido y configuración heredados que todavía deben adaptarse. No interpretar sus dominios, APIs, cuentas o instrucciones de despliegue como recursos de este proyecto. El workflow de sincronización hacia `frontend-mirror` fue retirado.

Stack heredado: Next.js, React, Tailwind CSS y pnpm. Comandos: `pnpm install`, `pnpm dev`, `pnpm build`, `pnpm lint`.
